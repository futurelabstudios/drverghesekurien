# Memories

First-hand stories about Dr. Verghese Kurien, from the people who lived them.

**Who should write here:** farmers, cooperative members, Amul / NDDB / GCMMF / IRMA staff, IRMA students and faculty, family, neighbours, journalists, officials — anyone with a real memory.

## How to add yours

1. Copy [`_TEMPLATE.md`](_TEMPLATE.md).
2. Name the file `YYYY-your-name-short-title.md` (year the memory happened), e.g. `1988-priya-shah-irma-fieldwork.md`.
3. Fill it in and open a pull request. See the [Contributing guide](../CONTRIBUTING.md).

Writing in Gujarati, Hindi, Malayalam or any other language is welcome. An English summary helps more readers.

## Rules for memories

- Tell **your own** experience, or clearly label something you heard from someone else.
- Don't share private details about living people without their consent.
- Be fair — critical memories are welcome when they are honest and respectful.
